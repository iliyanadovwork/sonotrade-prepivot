# Sonotrade Admin Panel

Admin panel for managing Sonotrade application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run in development mode (runs on port 3001):
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
npm start
```

## Features

- Next.js 16 with App Router
- StyleX for styling
- shadcn/ui components ready (initialize with: `npx shadcn@latest init`)
